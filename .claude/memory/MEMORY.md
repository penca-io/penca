## Architecture — current direction
- [project_branching_main_only_mvp.md](project_branching_main_only_mvp.md) — Branching is MAIN-ONLY for the MVP (CHA-515 fail-fast guard at `create_branch`); multi-level fork-off-a-fork DEFERRED to CHA-509 (planner enumerates one immediate parent, no recursion). Single-base read invariant holds (`Plan.base_cold_storage` = one parent capped at fork seq; AuditPlan mirrors). Don't build/assume multi-level in branching/lineage/audit work.
- [project_branch_create_flush_to_cold.md](project_branch_create_flush_to_cold.md) — TARGET: per-branch = fully isolated stack (Flight SQL/Write/Query/Meta/PG/Lifecycle/Cache), only S3 shared, branches never coordinate; CreateBranch = flush parent to S3 + spawn empty stack. NOT shipped yet — current code is metadata-copy + base_tx pin in one shared stack, no flush (verified 2026-05-30, CHA-356). Obsoletes CHA-67 v1/v2.
- [project_pg_no_wal_archive.md](project_pg_no_wal_archive.md) — Per-branch PG uses cross-AZ replicas for durability, NOT WAL archiving or base backups. Cold-tier audit log replaces PITR.
- [project_control_plane_three_tier.md](project_control_plane_three_tier.md) — Control plane: penca-catalog (global) → penca-branch (per catalog) → per-branch stack. State stored as MVCC Penca tables (dogfoods CHA-240). Resolve returns endpoints, never proxies. Control-plane PG (catalog/branch_store) is a separate GLOBAL instance → per-branch-transactional state (counters atomic with tx_log) lives in the per-branch stack, not branch_store.
- [project_mut_seq_num_sequence.md](project_mut_seq_num_sequence.md) — mut_seq_num (CHA-431) = lock-free per-(table,branch) PG SEQUENCE (nextval), NOT a locked counter row; within-tx data ordering only (never cross-tx), so no atomic-with-visibility/gapless needed. - [project_persist_cdc_purge_governs_reads.md](project_persist_cdc_purge_governs_reads.md) — CHA-444 (implemented 2026-06-21): Persist=committed-only CDC (no open-tx clamp); reads fenced at max(Pu,W_snap) not persist (hot serves persisted-but-unpurged (W_snap,P]); Purge owns aborts on an independent gapless abort_seq_num/Pa axis + cleans expired-begins (union; supersedes CHA-467); tx_log GC trails purge on seq.
